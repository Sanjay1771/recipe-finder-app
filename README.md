# 🍽️ Recipe Finder App

A modern web application to search, discover, and save recipes using the Spoonacular API.

## Tech Stack

| Layer      | Technology         |
|------------|--------------------|
| Frontend   | React + Material UI |
| API        | Spoonacular API    |
| Database   | Supabase           |
| HTTP Client| Axios              |

## Project Structure

```
RecipeFinderApp/
├── frontend/      → React application
├── backend/       → (Future) API server
└── README.md      → Project overview
```

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm (v9+)
- Spoonacular API key
- Supabase project credentials

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
